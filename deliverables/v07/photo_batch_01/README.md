# AB Kitchen V0.7 - 20 recipe-photo batch (safe standalone assets)

This folder contains 20 separately generated JPEG food photos, one file for each recipe missing a bundled photo on the V0.7 main branch. File names match the recipe IDs exactly.

IMPORTANT: These are original AI-generated photorealistic food illustrations (Adobe Firefly), **not camera-taken documentary photographs**. They were individually reviewed for dish matching. Image representation is illustrative; ingredient/halal compliance is determined from the recipe, not from image pixels.

**This branch changes no existing application files or recipe records.** Images are staged here for review; connecting them to `assets/photos` and `RecipePhoto.picturedRecipes` requires a separate safe patch after acceptance.
